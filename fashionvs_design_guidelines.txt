# FashionVS Design Guidelines

## Overview

This document outlines the design language and theme rules used in the FashionVS fashion visual search website. It serves as a reference for maintaining design consistency across all components and pages. The design system is implemented using Tailwind CSS, with custom theme configurations defined in `tailwind.config.js`.

## Typography

### Font Family
Three primary font families for different use cases:

```
font-sans: ['Inter', 'system-ui', 'sans-serif'] - Primary UI and body text
font-display: ['Playfair Display', 'serif'] - Fashion headings and elegant display text
font-fashion: ['Poppins', 'system-ui', 'sans-serif'] - Modern fashion branding and labels
```

### Font Sizes
Tailored for fashion content and visual hierarchy:

- text-xs: Price tags, size labels, fine print
- text-sm: Product details, secondary information
- text-base: Default body text, descriptions
- text-lg: Product names, category labels
- text-xl: Section subtitles, brand names
- text-2xl: Category headings
- text-3xl: Page section headings
- text-4xl: Main page headings
- text-5xl: Hero section headings
- text-6xl: Brand displays, fashion statements

### Font Weight
Fashion-focused weight usage:

- font-light: Elegant descriptions, luxury branding
- font-normal: Regular product information
- font-medium: Product names, navigation
- font-semibold: Category headings, important details
- font-bold: Call-to-action buttons, sale prices
- font-extrabold: Fashion statements, brand names

## Usage Guidelines

1. Color Philosophy:
   - Use pink as the primary brand color for fashion-forward elements
   - White backgrounds keep focus on fashion items
   - Purple secondary colors add sophistication
   - Accent colors categorize different fashion segments

2. Typography Hierarchy:
   - Playfair Display for elegant fashion statements and luxury branding
   - Inter for clean, readable UI text and product information
   - Poppins for modern fashion labels and contemporary branding

3. Fashion-Specific Considerations:
   - Images should have consistent lighting and backgrounds
   - Product cards need space for high-quality imagery
   - Color accuracy is crucial for fashion items
   - Size and fit information should be prominently displayed

4. Visual Search Elements:
   - Upload areas should be intuitive and visually appealing
   - Results should be displayed in a clean grid format
   - Similarity scores can use color-coded indicators

5. Responsive Fashion Design:
   - Mobile-first approach for shopping behavior
   - Touch-friendly size selectors and color pickers
   - Optimized image loading for visual search results

6. Accessibility:
   - High contrast between text and backgrounds
   - Alternative text for all fashion images
   - Keyboard navigation for all interactive elements
   - Screen reader friendly product information

7. Fashion Brand Voice:
   - Sophisticated yet approachable
   - Emphasize style discovery and personal expression
   - Clear calls-to-action that inspire fashion choices
   - Inclusive language for all body types and styles

8. Performance Considerations:
   - Optimized image loading for fashion galleries
   - Progressive loading for visual search results
   - Efficient caching for frequently accessed items

Note: This design system is implemented using Tailwind CSS with custom theme configurations. The color palette and components should be defined in `tailwind.config.js` for consistent application across the fashion visual search platform.
