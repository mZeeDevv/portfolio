# Portfolio Design Guidelines - Software Engineer

## Overview

This document outlines the design language and theme rules for a software engineer's personal portfolio website. The design system emphasizes professionalism, technical expertise, and modern aesthetics while maintaining excellent readability and accessibility. The theme uses a light, clean approach with subtle accents to create a sophisticated yet approachable presence. The design system is implemented using Tailwind CSS with custom configurations.

## Typography

### Font Family
Three primary font families for different use cases:

```
font-sans: ['Inter', 'system-ui', 'sans-serif'] - Primary UI, body text, and general content
font-mono: ['JetBrains Mono', 'Fira Code', 'monospace'] - Code snippets, technical details
font-display: ['Space Grotesk', 'system-ui', 'sans-serif'] - Headings, hero text, professional branding
```

### Font Sizes
Optimized for technical content and professional presentation:

- text-xs: Code comments, fine print, metadata
- text-sm: Code snippets, technical details, captions
- text-base: Default body text, descriptions, content
- text-lg: Section subtitles, skill labels, project titles
- text-xl: Card headings, technology names
- text-2xl: Section headings, page subtitles
- text-3xl: Main page headings, section titles
- text-4xl: Hero section headings, name/title
- text-5xl: Portfolio name, main branding
- text-6xl: Large hero displays, impact statements

### Font Weight
Professional weight usage for technical content:

- font-light: Supporting text, descriptions
- font-normal: Regular body text, content
- font-medium: Navigation, labels, button text
- font-semibold: Card titles, section headings
- font-bold: Main headings, call-to-actions
- font-extrabold: Hero text, portfolio name

## Usage Guidelines

1. Color Philosophy:
   - Use blue as the primary professional color
   - White and light backgrounds for clean presentation
   - Subtle gradients for visual interest without distraction
   - Accent colors to categorize different technologies and skills

2. Typography Hierarchy:
   - Space Grotesk for professional headings and branding
   - Inter for clean, readable body text and UI elements
   - JetBrains Mono for code snippets and technical content

3. Professional Considerations:
   - Maintain generous whitespace for easy reading
   - Ensure high contrast for accessibility
   - Use consistent spacing and alignment
   - Keep animations subtle and purposeful

4. Portfolio-Specific Elements:
   - Project cards should highlight key information clearly
   - Skills should be visually organized and easy to scan
   - Contact information should be prominently accessible
   - Code samples should be properly formatted and highlighted

5. Responsive Design:
   - Mobile-first approach for all layouts
   - Touch-friendly interactive elements
   - Optimized loading for project images and demos
   - Collapsible navigation for mobile devices

6. Accessibility:
   - High contrast ratios for all text
   - Alternative text for project images
   - Keyboard navigation support
   - Screen reader friendly content structure

7. Professional Brand Voice:
   - Clean and technical without being cold
   - Confident but approachable
   - Focus on problem-solving and innovation
   - Clear communication of technical expertise

8. Performance Considerations:
   - Optimized images for project showcases
   - Lazy loading for project galleries
   - Minimal JavaScript for smooth interactions
   - Fast loading times for professional impression

Note: This design system should be implemented using Tailwind CSS with custom theme configurations defined in `tailwind.config.js`. The color palette and components ensure a cohesive, professional appearance throughout the software engineer portfolio website.
